# 课程内容库

这里保存从教材、教师用书、练习册和视听资料中核验出的课程内容。它为计划和语音教学提供事实来源，但不代表学习者已经学习或掌握。

## 三层结构

| 层 | 内容 | 是否代表已学 |
|---|---|---|
| 课程地图 | 单元顺序、主题、语言目标和来源覆盖 | 否 |
| 单元教学包 | 词汇、语法、发音、技能任务、工作迁移和验收任务 | 否 |
| 学习证据 | 每日作答、录音、错误、分数及延迟复习 | 是，保存在 `progress/` 等目录 |

## 单元文件原则

每个单元至少包括：

1. 教材目标和来源页码；
2. 可直接用于语音教学的核心内容；
3. 听、说、读、写任务；
4. 面向工作的迁移任务；
5. 可收集的学习证据；
6. 明确的资料缺口；
7. `learner_status: no_evidence` 初始状态。

原版PDF、音频、视频、软件、答案册和完整测评文件不提交到本仓库。本仓库只保存摘要、索引、个性化任务、学习证据，以及约束AI所必需的最小核验事实或答案。
