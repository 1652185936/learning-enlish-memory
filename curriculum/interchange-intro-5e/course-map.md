# Interchange Fifth Edition Intro 课程地图

## 使用边界

- 本文件描述教材与配套资源，不描述学习者已经掌握了什么。
- `curriculum_band: CEFR_A1`是教材级别定位，不是学习者测评结果；学习者当前仍为`no_evidence`。
- 页码同时写“印刷页 / PDF页”。PDF页从1开始计数，便于在阅读器中直接定位。
- 工作场景任务均是仓库的个性化扩展，不是教材原文。
- 这里只记录内容位置、教学顺序和证据要求，不复制教材长段文字、完整练习或答案。

## 口试与半册测试位置

- 单元口试题库：`Interchange_Intro_Assessment.zip` → `Intro Assessment/Intro Oral Quizzes/IC5_Intro_OQ_Question_Bank.pdf`，按Unit 1至Unit 16分区取题。
- 口试评分表：同目录`IC5_Intro_OQ_Scoring_Sheet.pdf`；官方维度为理解、流利度、语法、词汇、发音，各0-5分。
- Units 1-8完成后：使用`Unit Tests 1-8 version A`作首次半册测试；Version B保留作延迟复测。
- Units 9-16完成后：使用`Unit Tests 9-16 version A`作首次半册测试；Version B保留作延迟复测。
- 官方材料提供题目与评分结构；仓库自定的推进阈值见[四课次教学与证据框架](lesson-framework.md)，不得冒充出版社官方及格线。

- 核心课：16单元 × 4次60分钟 = 64次。

- 半册测试：2次60分钟。
- 计划合计：74次、约74小时；这是计划量，不是已完成时长。
- 当前课程与全部单元的学习者状态：`no_evidence`。只有真实课堂记录、首次作答、录音/转写和评分结果才能改变状态。
