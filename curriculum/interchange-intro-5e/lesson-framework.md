# Interchange Fifth Edition Intro：四课次教学与证据框架

## 适用范围

本框架用于Unit 1-16。每单元四课次，每次计划60分钟；课次ID采用`IC5-L0-U01-D1`格式。计划时长只有在当日实际完成并写入学习记录后，才能计为学习时长。

## D1-D4固定推进

| 课次 | 学生书推进 | 60分钟结构 | 最低证据 |
|---|---|---|---|
| D1 | 单元第1-2个印刷页 | 8分钟旧知提取；12分钟情境/词汇；15分钟原版音频首次听与核对；15分钟跟读和引导会话；10分钟不看稿短输出 | 原版音频第一遍结果；至少一段不看稿回答；未知词清单 |
| D2 | 单元第3个印刷页 | 8分钟提取；17分钟语法形式-意义-使用；10分钟控制练习；10分钟发音/听辨；10分钟替换问答；5分钟出口任务 | 首次答案与订正分开；至少3个独立例句；发音/听辨记录 |
| D3 | 单元第4-5个印刷页 | 8分钟提取；12分钟第二情境输入；15分钟音频细听；15分钟读写或互动任务；10分钟少提示角色扮演 | 一项听力细节结果；一轮少提示互动；读或写产物 |
| D4 | 单元最后1个印刷页 | 10分钟间隔提取；15分钟末页综合任务；10分钟Grammar Plus；10分钟精选WB；10分钟官方口试题；5分钟记录和复习安排 | WB首次答案；短写作/综合输出；口试五维分数；下一次复习日期 |

若某单元没有正式阅读栏目，D3/D4的“读写”改为对话信息提取、表格/清单书写或功能性短写作，不虚构教材阅读文章。

## 原版音频规则

1. 先不看脚本完成第一遍，记录听懂的要点或题目结果。
2. 第二遍允许暂停定位；第三遍才允许结合脚本或教师提示。
3. 跟读、影子练习与自由复述分开记录；跟读成功不等于能独立表达。
4. 语音模式无法直接播放本地原版音频时，只能用教师朗读/合成示例替代练习，必须标记`audio_mode: substitute`，不得冒充原版听力成绩。
5. TB脚本与答案仅用于首次作答后的核对，不复制到课程文件。

## 单元测评与双单元检查

- D4从官方Oral Question Bank的对应Unit分区抽题，使用官方五维评分表记录理解、流利度、语法、词汇、发音；保留原始回答或转写。
- 书面Written Quiz和学生书Progress Check属于双单元证据，只能在偶数单元完成后实施。奇数单元D4不得提前做或据此标记掌握。
- Units 1-8和9-16各使用Version A作首次半册测试；Version B保留作延迟复测，避免记忆答案。
- 自评、看稿复述、订正后的全对、已学习页数都不能单独证明独立使用能力。

## 状态与仓库自定门槛

以下门槛是本仓库的教学决策规则，不是Cambridge官方及格线。

| 状态 | 必须同时满足 |
|---|---|
| `no_evidence` | 尚无该单元真实学习证据；教材已整理也保持此状态 |
| `covered` | D1-D4均有独立日期的真实记录；核心听说及读写/功能性书写都有首次证据；实际时长可核对 |
| `meets_standard` | `covered`；代表性控制任务首次作答至少80%；官方口试至少18/25且五个维度均不低于3；所属双单元Written Quiz已有首次分项结果且关键目标达到80% |
| `can_use` | 在未见过的同类情境中无内容提示完成单元核心交际任务；关键信息完整、可理解；目标语法/词汇准确率至少80%；所需澄清不超过一次 |
| `retained` | 达到`can_use`后，在至少D+2和D+7两个不同日期、换人物或情境的无提示复测中仍达到同一标准 |

分数不足时保留真实首次结果，建立错误记录并补强；不得用订正分覆盖首次分。`retained`必须来自延迟证据，不能在D4当日授予。

## 每课记录最小字段

```yaml
course_id: IC5-L0
lesson_id: IC5-L0-U01-D1
date: YYYY-MM-DD
duration_minutes: null
source_pages: null
audio_mode: original | substitute | none
first_attempt_result: null
independent_output: null
errors_logged: []
next_review_date: null
learner_status_after: no_evidence
```

- `duration_minutes`记录真实时长，不能默认填60。
- `first_attempt_result`保留首次表现，不能只记录订正后结果。
- `learner_status_after`只能依据本页门槛更新；没有足够证据就继续`no_evidence`或保持原状态。

## 个性化工作迁移的边界

每个单元提供一个适配工作英语的迁移情境。它用于把教材语言迁移到真实目标，但明确属于“个性化扩展，非教材原文”。教师可以替换人物、地点、物品和任务，但不能把扩展任务写成出版社内容，也不能因完成教材机械练习而自动判定扩展任务通过。
