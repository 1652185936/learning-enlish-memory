# 知识库索引

这里保存值得重复使用的英语知识。每日发生了什么仍以 `progress/daily/` 为准；知识库只整理可复用内容。

## 分类

- [词汇与短语](vocabulary/README.md)
- [语法](grammar/README.md)
- [听力](listening/README.md)
- [口语](speaking/README.md)
- [重要概念与学习方法](concepts/README.md)

## 记录原则

1. 每条内容都应包含自己的英语例句或实际语境。
2. 标明来源日期或对应每日记录。
3. “见过”不等于“掌握”；状态必须由复习证据支持。
4. 需要复习的内容同时加入 `review/due.md`。
