# 每日学习记录

每日记录按年份保存：

```text
progress/daily/YYYY/YYYY-MM-DD.md
```

使用 [每日记录模板](../../system/templates/daily.md)。同一天只有一个主记录；后续信息追加到该文件，不重复创建。

## 状态含义

- `planned`：只有计划，尚未确认完成。
- `in_progress`：已开始，但学习者尚未确认结束。
- `completed`：学习者已确认完成，且有可记录的实际内容。
- `skipped`：计划未执行。

只有 `completed` 记录中的已确认时长和结果可以进入进度总览。系统初始化本身不算英语学习。
