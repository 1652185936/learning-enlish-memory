# 学习记忆系统规则

## 1. 证据优先

- 只保存学习者明确说过、做过或提供的材料。
- 自我感受可以记录，但必须标注为自我评估。
- 分数、时长、完成量和掌握程度不能推测。

## 2. 计划与完成分离

- `planned` 只表示准备做。
- 只有明确完成的活动才能更新累计次数与时长。
- 未完成计划可以标记 `skipped` 或调整日期，但不能伪装成成果。

## 3. 最小必要更新

一次普通学习结束后，通常只需要更新：

1. 当天的每日记录；
2. 实际涉及的知识或错误文件；
3. 必要的复习安排；
4. 由以上事实推导出的进度总览。

不应为了“看起来完整”而改动无关文件。

## 4. 错误生命周期

1. 首次确认错误时创建稳定 ID。
2. 重复出现时增加证据与次数，不新建重复条目。
3. 安排复习并在复习日志中记录结果。
4. 只有达到条目定义的掌握条件时才移入 `review/mastered.md`。

## 5. 复习安排

- 优先级：已过期复习 > 高频错误 > 当前阶段内容 > 新内容。
- 日期必须明确；无法确定时写 `待确认`。
- 实际复习结果优先于预设间隔。

## 6. 阶段总结

- 必须引用相关每日记录或测评证据。
- 区分“完成了什么”“能力有何证据变化”“仍然薄弱什么”。
- 新计划应由阶段结果推导，而不是机械复制旧计划。

## 7. 文件与日期

- 时区：Asia/Dubai。
- 日期格式：`YYYY-MM-DD`。
- 周计划使用 ISO 周编号：`YYYY-Www`。
- 每日文件路径：`progress/daily/YYYY/YYYY-MM-DD.md`。
- 模板是占位格式，不计入真实学习数据。
