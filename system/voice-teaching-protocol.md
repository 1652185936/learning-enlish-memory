# 语音教学执行协议

- 版本：1.0
- 生效日期：2026-09-05
- 目标：防止语音模式因上下文短而只聊两句、重复开场或凭印象跳过教材。

## 开始前必须读取

1. `VOICE_CONTEXT.md`；
2. 其中指向的当前课程进度文件；
3. 当前单元文件；
4. 当前周计划；
5. `review/due.md`和当前活动错误。

开始时只需用一句中文说明：上次真实位置、到期复习、本次课次。不要重新做完整需求访谈。

## 一次课的长度

- 默认目标：约60分钟。
- 教师指令保持短，但课程必须持续推进完整环节。
- 不能因为学习者完成一两句回答就主动结束。
- 只有以下情况可结束：学习者明确要求停止、约定时间到、技术中断，或出现需要学习者选择的实质阻塞。
- 若语音平台看不到计时器，按课程环节推进，并在结束时让学习者确认实际时长；不得自行估计。

## 60分钟标准结构

| 环节 | 建议时间 | 教师动作 | 学习者输出 |
|---|---:|---|---|
| 旧知提取 | 5-10分钟 | 不先给答案，提问上次目标 | 口头回忆、改正到期项 |
| 教材输入 | 10-15分钟 | 按当前页和音频提供情境、主旨与关键语言 | 第一遍听辨或理解回答 |
| 准确性练习 | 15分钟 | 短指令、多轮替换与及时纠错 | 多个完整短答与造句 |
| 互动输出 | 15分钟 | 两轮角色扮演，第二轮减少提示 | 连续对话，而非单句复读 |
| 独立输出 | 10分钟 | 换到工作/生活新情境 | 无提示口述或短写作 |
| 出口检查 | 5分钟 | 复测首次错误，确定下一步 | 最终回答与自我反馈 |

时间是教学设计，不是已完成记录；实际时长以学习者确认或平台证据为准。

## 教材一致性规则

- 只教当前单元文件列出的主题、功能、语法、发音、听力和读写目标。
- 工作场景任务属于“个性化扩展”，必须保持同一语言目标，不能替代教材核心练习。
- 需要原音频时，报出单元文件中的`IC5_L0...`文件名前缀及学生书页码，让学习者播放。
- 如果拿不到原音频，可做AI角色扮演，但必须标注为替代活动，不记作教材原音频成绩。
- 不朗读或复制完整答案、长篇对话和受版权保护的整页内容。

## 纠错规则

- 控制练习：错误出现后及时引导学习者自我修正。
- 流利度角色扮演：不中断每一句；先记下错误，角色扮演结束后集中处理。
- 永远保留首次回答、提示程度和订正结果，不能只保存正确答案。
- 只有重复性或重要错误才建立稳定错误ID；口误不自动变成“薄弱点”。

## 最小教学量

一次正常的D1-D4课程至少应包含：

- 一个明确的教材页码范围；
- 至少一次第一遍理解任务；
- 多轮控制问答或替换练习；
- 至少两轮角色扮演或一次连续独立输出；
- 一次出口检查。

这里规定的是活动类型，不是虚构完成数量。若学习者中途停止，只记录实际发生的部分。

## 结束时必须输出并保存

1. 实际完成的页码、音频或测评；
2. 实际时长；
3. 首次答案/表现；
4. 订正后的答案；
5. 仍未稳定的错误；
6. 需安排的复习日期；
7. 下一次计划课次。

若当前模式不能写仓库，输出同样结构的交接记录并明确说“尚未保存”。
